## 🚀 進行中のオープンソースプロジェクト

```
+--------------------------------------------------------------------------+
|  flow-kprobe  [Rust / C / eBPF]                                          |
|  TCPソケットライフサイクルの追跡とマイクロ秒単位のパケット遅延分析を行う     |
|  ゼロオーバーヘッドLinuxカーネルプローブエンジン。                         |
+--------------------------------------------------------------------------+
|  wire-sieve   [C / XDP]                                                  |
|  NICドライバ層で直接動作し、10GbEコアあたり毎秒1,480万パケット(14.8M pps) |
|  を処理する高スループットL4ステートレスパケットディスパッチャ。            |
+--------------------------------------------------------------------------+
|  nanotrace    [Go / Rust / libbpf]                                       |
|  ターミナル上でサブマイクロ秒精度のヒストグラムを描画し、Linuxシステム     |
|  コールのテールレイテンシを可視化する軽量CLIツール。                       |
+--------------------------------------------------------------------------+
```

### 1. `flow-kprobe`
- **コアアーキテクチャ**: 最新のCO-RE（`Compile Once - Run Everywhere`）eBPF技術を採用し、`tcp_v4_connect`、`tcp_set_state`、`tcp_close`などの重要カーネル関数へ非侵襲的にフック。
- **特徴**: コンテキストスイッチのオーバーヘッドを発生させず、超低遅延でユーザ空間へリングバッファイベントをストリーミング。
- **ベンチマーク**: 毎秒10万リクエスト（100k req/s）の負荷下でも、8コアホストでCPU使用率`0.8%`未満を維持。

### 2. `wire-sieve`
- **コアアーキテクチャ**: XDPネイティブモード（`XDP_TX` / `XDP_PASS`）でカーネルネットワークスタックを早期バイパスし、異常パケットをNIC段で即座に破棄、正当なパケットを高速ルーティング。
- **設計思想**: メカニカルシンパシー（Mechanical Sympathy）、ゼロアロケーション（Zero-Allocation）メモリプール、キャッシュライン整列パケットメタデータ構造。

### 3. `nanotrace`
- **コアアーキテクチャ**: `sys_enter`および`sys_exit`トレースポイントにアタッチし、ストレージやネットワークスレッドのシステムコール所要時間をマイクロ秒単位で正確に計測。
- **出力形式**: 外部Web UIに依存せず、純粋なターミナル上でASCIIパーセンタイルラダー（`p50`, `p95`, `p99`, `p99.9`）グラフを描画。

## 📊 エンジニアリング原則とコード哲学

1. **メカニカルシンパシー（ハードウェアへの共感）最優先**: ソフトウェアは物理ハードウェア上で動作します。キャッシュラインアライメント、分岐予測器への最適化、NUMAノード局所性を抽象化よりも尊重します。
2. **暗黙的より明示的**: マジックのような抽象化を排除します。明確なエラーハンドリング、厳密な所有権セマンティクス、ランタイムの間接参照（Indirection）最小化を徹底します。
3. **可観測性は後付けではない**: 本番環境において性能劣化なしに内部状態を検査できないシステムは、未完成のシステムです。
4. **データ指向設計（Data-Oriented Design）**: 深いオブジェクト階層よりも、連続したメモリ配列とベクトル化演算に最適化されたデータ構造を採用します。
