## 🚀 सक्रिय ओपन सोर्स प्रोजेक्ट्स

```
+--------------------------------------------------------------------------+
|  flow-kprobe  [Rust / C / eBPF]                                          |
|  TCP सॉकेट लाइफसाइकिल ट्रैकिंग और माइक्रोसेकंड पैकेट लेटेंसी विश्लेषण के     |
|  लिए ज़ीरो-ओवरहेड लिनक्स कर्नेल प्रोब इंजन।                              |
+--------------------------------------------------------------------------+
|  wire-sieve   [C / XDP]                                                  |
|  NIC ड्राइवर स्तर पर चलने वाला हाई-थ्रूपुट L4 स्टेटलेस पैकेट डिस्पैचर,    |
|  जो प्रति 10GbE कोर 14.8M पैकेट प्रति सेकंड प्रोसेस करने में सक्षम है।    |
+--------------------------------------------------------------------------+
|  nanotrace    [Go / Rust / libbpf]                                       |
|  टर्मिनल में सब-माइक्रोसेकंड हिस्टोग्राम के साथ लिनक्स सिस्टम कॉल की      |
|  टेल लेटेंसी (Tail Latency) मापने का हल्का CLI टूल।                      |
+--------------------------------------------------------------------------+
```

### 1. `flow-kprobe`
- **मुख्य आर्किटेक्चर**: आधुनिक CO-RE (`Compile Once - Run Everywhere`) eBPF तकनीक द्वारा `tcp_v4_connect`, `tcp_set_state` और `tcp_close` जैसे महत्वपूर्ण कर्नेल फ़ंक्शंस में बिना किसी रुकावट के हुक करता है।
- **प्रमुख विशेषता**: बिना किसी कॉन्टेक्स्ट-स्विचिंग ओवरहेड के यूज़र-स्पेस में अल्ट्रा-लो लेटेंसी रिंग बफ़र इवेंट स्ट्रीम करता है।
- **बेंचमार्क**: 100,000 अनुरोध/सेकंड के लोड पर 8-कोर होस्ट में CPU उपयोग `0.8%` से नीचे रहता है।

### 2. `wire-sieve`
- **मुख्य आर्किटेक्चर**: लिनक्स नेटवर्क स्टैक को XDP नेटिव मोड (`XDP_TX` / `XDP_PASS`) से बाईपास करता है ताकि असामान्य ट्रैफ़िक को तुरंत ब्लॉक किया जा सके और वैध पैकेट तेज़ी से रूट किए जा सकें।
- **डिज़ाइन सिद्धांत**: मैकेनिकल सिम्पथी (Mechanical Sympathy), शून्य आवंटन (Zero-Allocation) मेमोरी पूल, और कैश-लाइन अलाइन्ड पैकेट मेटाडेटा संरचना।

### 3. `nanotrace`
- **मुख्य आर्किटेक्चर**: `sys_enter` और `sys_exit` ट्रेसप्वाइंट से जुड़कर स्टोरेज और नेटवर्क I/O थ्रेड्स के सिस्टम कॉल निष्पादन समय को सटीक रूप से मापता है।
- **आउटपुट**: बिना किसी बाहरी वेब निर्भरता के सीधे टर्मिनल में ASCII प्रतिशतक सीढ़ी (`p50`, `p95`, `p99`, `p99.9`) ग्राफ़ रेंडर करता है।

## 📊 इंजीनियरिंग सिद्धांत और कोड दर्शन

1. **मैकेनिकल सिम्पथी सर्वोपरि**: सॉफ़्टवेयर वास्तविक हार्डवेयर पर चलता है। कैश-लाइन अलाइनमेंट, ब्रांच प्रेडिक्शन और NUMA नोड लोकैलिटी को सैद्धांतिक अमूर्तता पर प्राथमिकता दी जाती है।
2. **स्पष्टता अंतर्निहितता से बेहतर है**: कोई जादुई कोड नहीं। स्पष्ट त्रुटि हैंडलिंग, सख्त मेमोरी ओनरशिप नियम और रनटाइम इनडायरेक्शन का न्यूनतम उपयोग।
3. **ऑब्जर्वेबिलिटी बाद का विचार नहीं है**: यदि किसी सिस्टम को प्रोडक्शन में प्रदर्शन में गिरावट के बिना वास्तविक समय में जाँचा नहीं जा सकता, तो वह अधूरा है।
4. **डेटा-उन्मुख डिज़ाइन (Data-Oriented Design)**: गहरी ऑब्जेक्ट पदानुक्रमों के बजाय मेमोरी ऐरे और वेक्टराइज़्ड ऑपरेशंस के लिए अनुकूलित डेटा लेआउट।
