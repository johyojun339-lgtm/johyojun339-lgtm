## 🚀 진행 중인 오픈소스 프로젝트

```
+--------------------------------------------------------------------------+
|  flow-kprobe  [Rust / C / eBPF]                                          |
|  TCP 소켓 생명주기 추적 및 마이크로초 단위 패킷 지연시간 측정을 위한       |
|  제로 오버헤드 리눅스 커널 프로브 엔진.                                   |
+--------------------------------------------------------------------------+
|  wire-sieve   [C / XDP]                                                  |
|  NIC 드라이버 레벨에서 직접 구동되어 10GbE 코어당 초당 1,480만 패킷        |
|  (14.8M pps)을 처리하는 고처리량 L4 무상태 패킷 디스패처.                |
+--------------------------------------------------------------------------+
|  nanotrace    [Go / Rust / libbpf]                                       |
|  터미널 환경에서 서브-마이크로초 히스토그램으로 리눅스 시스템 콜 테일       |
|  지연시간(Tail Latency)을 정밀 분석하는 경량 CLI 도구.                    |
+--------------------------------------------------------------------------+
```

### 1. `flow-kprobe`
- **핵심 아키텍처**: 최신 CO-RE(`Compile Once - Run Everywhere`) eBPF 기술을 활용하여 `tcp_v4_connect`, `tcp_set_state`, `tcp_close` 등 핵심 커널 함수에 무간섭 후킹.
- **주요 특징**: 컨텍스트 스위칭 부담 없이 사용자 공간으로 초저지연 링버퍼 이벤트를 스트리밍.
- **벤치마크**: 초당 10만 요청(100k req/s) 부하 환경에서도 8코어 호스트 기준 CPU 점유율 `0.8%` 미만 유지.

### 2. `wire-sieve`
- **핵심 아키텍처**: 리눅스 네트워크 스택을 조기 우회하는 XDP 네이티브 모드(`XDP_TX` / `XDP_PASS`)를 적용하여 변조된 패킷을 NIC 단계에서 즉각 차단하고 유효 패킷을 초고속 라우팅.
- **설계 철학**: 기계적 공감(Mechanical Sympathy), 무할당(Zero-Allocation) 메모리 풀, 캐시 라인 정렬 패킷 메타데이터 구조체 채택.

### 3. `nanotrace`
- **핵심 아키텍처**: `sys_enter` 및 `sys_exit` 트레이스포인트에 연결되어 스토리지 및 네트워크 I/O 스레드의 시스템 콜 소요 시간을 마이크로초 단위로 정밀 측정.
- **출력 방식**: 외부 웹 UI 의존성 없이 순수 터미널 환경에서 ASCII 백분위수 사다리(`p50`, `p95`, `p99`, `p99.9`) 그래프 시각화.

## 📊 엔지니어링 철학 및 코드 지향점

1. **기계적 공감(Mechanical Sympathy) 최우선**: 소프트웨어는 물리 하드웨어 위에서 실행됩니다. 캐시 라인 정렬, 분기 예측기 친화성, NUMA 노드 지역성을 이론적 추상화보다 우선시합니다.
2. **암시적인 것보다 명시적인 것**: 마법 같은 추상화(Magic)를 지양합니다. 명확한 에러 반환, 엄격한 메모리 소유권 규칙, 런타임 간접 참조(Indirection) 최소화를 추구합니다.
3. **관측성은 사후 고려 사항이 아니다**: 운영 환경에서 성능 저하 없이 내부 상태를 실시간 진단할 수 없는 시스템은 완성된 시스템이 아닙니다.
4. **데이터 지향 설계(Data-Oriented Design)**: 깊은 객체 계층 구조 대신 연속된 메모리 배열과 벡터화 연산에 최적화된 데이터 레이아웃을 구성합니다.
5. **결정론적 동시성 및 안전성(Deterministic Concurrency & Safety)**: 락프리(Lock-free) 동기화, 크기 제한 메모리 풀, 획득/해제(Acquire/Release) 메모리 배리어 시맨틱스를 통해 경쟁 상태와 성능 지터를 원천 차단합니다.
